VoidS3 0.2.0 adds a Windows x64 self-updater using signed GitHub Releases. Settings offers manual checks, release notes, download progress, and explicit Install and restart confirmation. Optional startup/daily checks notify you without installing. Stop running/queued transfers first; profiles, credentials, and paused transfers persist. Versions 0.1.1 and earlier need one manual installation to gain the updater.

This release also applies the supplied Figma workspace design and adds global pause/resume/cancel, folder-aware dragging between panes and from Explorer, recursive remote-folder downloads, and confirmed multi-file deletion with retryable failures. Branch pushes automatically build downloadable Windows installer/CLI artifacts.

No human has read, reviewed, edited, or otherwise manually intervened in this code. It was built for fun by AI agents from a human-supplied specification and visual references. This is not a security-audited or production-ready release. Normal 0.x releases are marked latest for updater discovery; this remains experimental software.

Windows installers have Tauri updater signatures but are not Authenticode-signed, so SmartScreen may appear. Verify SHA256SUMS for manual downloads. CLI upgrades remain manual. Uploads/downloads preserve existing destinations. Full overwrite/conflict sync, mirror deletion, scheduling, rich preview/editing, provider administration, benchmarks, and optimization remain unfinished. See docs/status.md and docs/validation.md for scope and evidence.
